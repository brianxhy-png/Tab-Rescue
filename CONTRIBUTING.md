# Contributing

Thanks for improving Tab Rescue.

1. Open an issue describing the bug or feature and how to reproduce it.
2. Make a focused branch from `main`.
3. Run `npm test` and `npm run check` (Node.js 20+).
4. Test the unpacked extension in Chrome: save, restore, rename, pin, delete, import/export, and an automatic backup.
5. Submit a pull request explaining behavior changes and any new permissions.

Please avoid adding remote services, tracking, or additional permissions without a clear user benefit and documentation update.
