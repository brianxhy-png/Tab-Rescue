# Roadmap

These are ideas, not shipped features.

- [ ] Group sessions by project and allow color labels.
- [ ] Optional tab deduplication on restore.
- [ ] A full-page dashboard for large session libraries.
- [ ] Keyboard shortcuts for saving the current window.
- [ ] Optional encrypted export using a user-supplied passphrase.
- [ ] Integration tests in a real Chrome profile and accessibility review.
- [ ] Chrome Web Store packaging after a privacy review and real user testing.

Keep the first release focused on reliable local save/restore. Do not claim automatic crash recovery without testing Chrome lifecycle and timing.
